# Solidification Microstructure Lab

Browser-based teaching tool for 2109519 Solidification of Casting, Faculty of Engineering, Chulalongkorn University.

Open the lab: https://chedtha.github.io/solidification-lab/

- Grain scale: cellular-automaton model of grain structure in a casting (80 x 50 mm).
- Dendrite scale: phase-field model of equiaxed and columnar dendrites with a solute map.

The whole lab is the single file `index.html`; it needs no installation and no server-side code.
